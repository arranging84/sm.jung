# family-dash — 우리 집 가족 대시보드

거실 TV용 가족 대시보드입니다. 파일 하나(`index.html`)로 완결되어 서버·빌드 도구 없이 열립니다.

- **게시 주소** — https://arranging84.github.io/sm.jung/
  (GitHub Pages · 소스: `gh-pages` 브랜치 루트 · HTTPS 강제)
- **이 브랜치(main)의 `family-dash/index.html`** — 게시본과 같은 파일의 사본입니다.
- **사이트를 고칠 때** — `gh-pages` 브랜치의 `index.html` 을 고쳐 푸시하면 1분 안에 반영됩니다. 이 브랜치(main)의 사본은 안내용이라 고쳐도 게시되지 않습니다.
- **개인정보** — 게시본에는 개인 일정·이름이 들어 있지 않습니다. TV에서 열고 ⚙️ 설정에
  · 구글 캘린더 Apps Script URL
  · 구성원 이름
  · 날씨 위치(위도·경도)
  을 넣으면 그 값은 그 브라우저(localStorage)에만 저장되고 사이트 파일에는 남지 않습니다.
- **화면 잠금** — 처음 열 때 4자리 PIN을 묻습니다(해제 상태는 기기별로 기억).
